Frequently Asked

Common Questions

Quick answers to the most common questions about this application.

How do I run this website locally?

Install Flask using pip install -r requirements.txt and run python app.py. The server runs at http://127.0.0.1:5000/.

Is this template mobile responsive?

Yes! It uses a modern CSS system with fluid grid layouts, flexible media queries, and a custom mobile drawer navigation.

Where do form submissions go?

The form data is validated and safely inserted into the local SQLite database (database.db). You can view, manage, and delete all records in the Inbox.

Can I add more pages?

Easily! Create a new template extending base.html, add a route function in app.py with @app.route('/your-page'), and add it to the navbar.
